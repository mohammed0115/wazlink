# SIDEBAR-SEMANTIC-ICONS — Navigation Clarity Report

**Baseline:** `ca4613a`  
**النطاق:** تحسين دلالة التنقل بصريًا فقط؛ لا تغيير للمسارات أو البيانات أو تكامل WhatsApp التجريبي.

## التغيير المنفذ

استبدلت الرموز النصية العامة في Sidebar بأيقونات SVG خطية مستقرة ومقروءة. أصبح لكل Route رمز متصل بمعناه بدل أن يتطلب من المستخدم قراءة النص أولًا.

| المجموعة | الأمثلة |
|---|---|
| الاكتشاف | عدسة بحث، سجل عمليات، جدول نتائج |
| العملاء | مستخدمون، جهة اتصال، مبنى شركة |
| المبيعات | Kanban، مصافحة للصفقات، مهمة، تقويم |
| التواصل | صندوق وارد، **أيقونة WhatsApp خضراء واضحة**، هاتف للمكالمات |
| الذكاء | Sparkles، رسالة ذكية، Bot |
| النظام | Workflow، chart، plug، gear |

أيقونة WhatsApp مرسومة كفقاعة محادثة مع سماعة هاتف وتستخدم اللون الأخضر `#25D366` في الحالة العادية، ثم تنتقل إلى لون الحالة النشطة المتوافق مع نظام التصميم. لا تدعي الأيقونة وجود WhatsApp API أو قناة حية؛ تبقى المحادثات Mock محلية.
