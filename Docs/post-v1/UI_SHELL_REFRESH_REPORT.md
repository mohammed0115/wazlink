## Icon System وActive Navigation

استخدم التحديث رموز التنقل الحالية ولم يبدل أي `navItem` أو route. فقط عُززت الرؤية الحجمية واللونية: الرئيسية سماوي، الاكتشاف slate-blue، CRM أخضر، الذكاء بنفسجي هادئ، الصفقات وردي هادئ، Inbox أزرق، AI كهرماني، المهام cyan، والتحليلات teal. لا تعتمد الحالة النشطة على اللون وحده؛ تضاف خلفية واضحة ومؤشر جانبي ووزن نص أعلى.

## Topbar وWorkspace

أصبحت Topbar بيضاء بارتفاع 76px على Desktop وحد سفلي دقيق. توسع Command Bar إلى حد 620px بحدود هادئة وfocus ring سماوي، بينما صار «اكتشاف جديد» زرًا outline ثانويًا. تستخدم مساحة العمل `#F8FAFC` تقريبًا مع gutter يبلغ 42px Desktop، وCards صفحات الشحنات تبقى بيضاء وحدودها خفيفة من دون ظلال ثقيلة. كبرت H1 ضمن نطاق 30–42px مع تسلسل عربي أوضح.

## Mobile وRTL والوصول

تنتقل Sidebar عند `max-width:900px` إلى Drawer فاتحة بعرض أقصى 274px، مع العلامة والأيقونات والتسميات نفسها وoverlay بصري خفيف عند الفتح. تبقى القائمة المطوية Icons-first مع tooltip native من `title`، ولا تخفي الشعار أو الأيقونات. احتُفظ بـRTL، وبـsemantic buttons/nav، وبـfocus-visible القائم في `base.css`، وبـReduced Motion لقواعد S8؛ لم يتغير Theme Toggle أو السلوك الداكن.

معاينة Desktop تمت عند 1440×900 و1920×1080 على Dashboard، إضافة إلى Discovery وLead 360 وCopilot. أظهر فحص collapsed بقاء الشعار والأيقونات مرئية. أُجريت لقطة محمولة 390×844، لكن أداة المعاينة قدمت viewport CSS أوسع من 390px، لذلك سجّل فحص Drawer كـ**مراجعة CSS** وليس ادعاء اختبار تفاعل جهاز حقيقي.
