# REFERENCE-ALIGNMENT — Google Maps Extractor Scenario Report

**المرجع المرئي:** https://gmapsextractor.com/  
**نطاق المواءمة:** تسلسل تجربة المستخدم فقط؛ لا نسخ هوية أو محتوى أو استخراج فعلي أو تكامل خارجي.

## ما تم نقله إلى «نمو»

أصبح سيناريو الاستخراج داخل نمو يبدأ بنفس المنطق الذي يتوقعه مستخدم أدوات استخراج الشركات: إدخال استعلامات متعددة، تشغيل عملية واحدة قابلة للتتبع، متابعة التقدم، فتح نتائج منظمة، اختيار حقول ملف Excel، ثم تنزيل محلي. طبقت المواءمة بلغتها العربية ونظام تصميم نمو، من دون محاكاة ادعاء اتصال فعلي بخرائط الأعمال.

| مبدأ تجربة المستخدم | التنفيذ في «نمو» |
|---|---|
| استعلامات متعددة | textarea يحمل أمثلة `النشاط | المدينة`، مع إضافة 3 استعلامات إلى 3 كلمات و3 مواقع و9 مجموعات بحث. |
| تسلسل واضح | شارة «بحث → تشغيل → نتائج → Excel» في مساحة الاكتشاف، وإظهار Job وتقدمها الحاليين أصلًا. |
| قيمة الملف قبل التصدير | لوحة حقول الهاتف والبريد والموقع وإنستغرام وواتساب، واختيار أعمدة Excel. |
| تصدير مستقل | باقة Scraper تنزّل CSV محليًا متوافقًا مع Excel وتنتهي بلا CRM تلقائي. |
| CRM اختياري | تظهر باقة CRM نمو بعد النتائج كتـرقية مستقلة فقط لإدارة Leads والمبيعات. |

## الحدود

المرجع الخارجي ألهم المسار المرئي فقط. يظل النموذج محليًا ببيانات ثابتة: لا Google Maps API ولا scraping ولا credits حقيقية ولا proxy ولا export server. كما لا تصبح باقة CRM جزءًا إلزاميًا من باقة Scraper.
