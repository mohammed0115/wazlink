# Legacy React Mockup — نموذج React قديم (غير مستخدم)

هذه الملفات كانت داخل `client/src` ضمن سكافولد القالب، ولم تكن جزءًا من تطبيق «نمو» المنفذ.

`Home.tsx` نموذج React منفصل لنفس الفكرة، لكنه يحمل **مصدر حقيقة ثانيًا**:
مصفوفة `leads` مكتوبة يدويًا بستة سجلات وهمية لا تمت بصلة إلى `client/js/data.js`،
ولا تحتوي `BUS-1042` أو عقود الإيراد والإسناد أو أي كيان من `ENTITY_MODEL.md`.

احتُفظ بها هنا للرجوع البصري فقط. لا تبنِ عليها ولا تعدها إلى `client/src`.
مسار React الفعلي هو `client/src` بعد تحويل V1، ومصدر الحقيقة يبقى `client/js/data.js`.
