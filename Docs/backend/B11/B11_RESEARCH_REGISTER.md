# B11 — Research Register

> Design only. Every material external claim in this pack is cited here. `STATUS` is exactly one of `VERIFIED` (read directly from the vendor's or standards body's own documentation during this authoring pass), `PARTIAL` (established by an authoritative-but-secondary source read during this pass, or corroborated across concordant sources without a primary read), `UNRESOLVED` (no readable source established the fact during this pass), or `CONTRADICTED`. No claim is promoted to `VERIFIED` on the strength of a secondary source, however reputable.

## 2. On the ratings

Two facts are `VERIFIED` and both were fetched from the primary vendor/standards documentation for the thing they describe — AWS's own S3 API reference for ETag semantics, and MDN's own header reference for `nosniff`. Four are `PARTIAL`: `B11-X-001`'s positive half was read from Hostinger's own page but its negative half is absence-of-evidence, and `B11-X-004`/`005`/`006` come from PortSwigger and OWASP, which are authoritative practice sources but not specifications. Three are `UNRESOLVED`, and each is unresolved for a different and honest reason: no readable source exists (`007`), the question is legal rather than technical (`008`), or another frozen phase already owns it (`009`).

**No unresolved item blocks Phase-1 architecture.** `B11-X-007` gates only a deferred adapter; `B11-X-008` cannot block because the design is correct under every possible answer; `B11-X-009` belongs to B5. `CLASS_A_UNRESOLVED = 0` follows from this, not from optimism.

## 3. Claims B11 explicitly does NOT make

- That Hostinger provides a managed object-storage service.
- That the deployed storage target supports pre-signed URLs, object lock, lifecycle rules, or checksum headers.
- That any provider ETag is a content hash.
- That WazLink performs malware or antivirus scanning (`B11-D-A024`, and `B11-AM-007` filed precisely so this is not implied elsewhere).
- That any specific statutory retention period applies to any file.
- That encryption at rest is guaranteed by the deployed target (`B11_SECURITY_PRIVACY.md` §3).
- That WhatsApp accepts any particular media size or type.
