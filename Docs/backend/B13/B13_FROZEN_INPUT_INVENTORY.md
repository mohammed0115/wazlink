# B13 — Frozen Input Inventory

> Design only. Catalogs the B0–B12 anchors B13 builds on. B13 modifies none of them; every clause below is quoted or restated for traceability, not re-decided. Anchor IDs are `FI-<phase>-##` and are referenced from every other B13 document instead of re-quoting frozen text.

## 1. Method

Each row names the frozen document, the exact clause, and the B13 document(s) that depend on it. This is the mechanical basis for `B0_DRIFT = 0` … `B12_DRIFT = 0` (`B13_VERIFICATION_MATRIX.md` §4): every frozen fact B13 relies on is listed here with its source, so a reviewer can check dependency without re-reading forty packages.
