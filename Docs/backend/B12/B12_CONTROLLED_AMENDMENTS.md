## B12-FIX.1 re-classification — decided, not assumed

An independent verification observed that the pre-FIX.1 `RetryWebhook` command would have required a new outgoing edge from a **frozen terminal state**, which would have contradicted `B12-AM-007`'s claim that the frozen terminals are unchanged. Each amendment was therefore re-classified from scratch rather than re-affirmed:

| Amendment | Re-classification | Why |
|---|---|---|
| `B12-AM-007` | **stays `ADDITIVE`** | The repair (`B12-D-A050`) keeps `failed` terminal and adds **no** edge to the frozen machine. The cell was inaccurate about a command elsewhere in the pack, not about the amendment's own effect on `BACKEND_STATE_MACHINES.md`; the command was corrected, and the wording now states the guarantee explicitly enough to be checkable. Removing `IntegrationConnection`'s `disabled` state shrinks a **B12-owned** machine and does not touch any frozen artifact |
| `B12-AM-003` | **stays `ADDITIVE`** | Four operations were added, all new paths under permissions already registered by `B12-AM-006`. No frozen operation is altered, no `filters`/`sort` marker is added, and no HTTP status outside `BACKEND_API_STANDARD.md`'s closed list is used |
| `B12-AM-002` | **stays `ADDITIVE`** | `lease_token` is a new column on a table this amendment already specifies column-by-column, and defining `dedup_key`'s composition (`B12-D-A056`) is inside its existing scope. The frozen constraint text — *"provider/dedup key unique; payload hash index"* — names the constraint and never defined the key, and both frozen notes remain honored verbatim |
| all others | unchanged | untouched by B12-FIX.1 |

**No compatible clarification was filed.** The temptation was to file one against `BACKEND_STATE_MACHINES.md` to "clarify" whether its terminals are truly terminal — but B12 does not need that sentence relaxed, and filing a clarification to make a count look conventional would be the fabrication this pack refuses elsewhere. **The repair removed the need for an amendment rather than the amendment removing the need for a repair.** `AMENDMENT_CLASSIFICATION_GAPS = 0`, `HIDDEN_NON_ADDITIVE_AMENDMENTS = 0`, `NON_ADDITIVE_AMENDMENT_COUNT = 0`.

**Why zero compatible clarifications.** B10 filed one, B11 filed two — each because a frozen artifact was internally ambiguous or promised something the new phase could not deliver. B12 found no such case: every frozen platform statement it depends on is either precise (ADR-005, the retry table, the timeout table, the receipt state machine) or explicitly deferred by its own author (B7's removed wakeup sweep, B9's synchronous posture, B11's storage capabilities). Where the frozen corpus was silent — queue topology, dead-letter storage, capability tri-values — silence is not ambiguity, and B12 fills it additively rather than "clarifying" a sentence that does not exist.
