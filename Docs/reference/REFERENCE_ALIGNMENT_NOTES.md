# Reference Alignment Notes — G Maps Extractor

**المصدر المرئي:** https://gmapsextractor.com/  
**الغرض:** استلهام تسلسل تجربة المستخدم فقط؛ لا نسخ هوية أو نصوص أو شعارات أو وظائف استخراج حقيقية.

## الملاحظات المنقولة إلى نموذج «نمو»

| مبدأ تجربة المرجع | المواءمة في «نمو» |
|---|---|
| حقل كبير لاستعلامات متعددة | `النشاط | المدينة`، سطر لكل استعلام، داخل مساحة الاكتشاف. |
| بدء مباشر لعملية استخراج | زر محلي ينقل إلى Job وحالات تقدم ونتائج ثابتة. |
| وعد واضح بقيمة التصدير | لوحة حقول الهاتف والبريد والموقع والتواصل واختيار أعمدة Excel. |
| تسلسل بسيط: query → progress → results → export | يظهر في Landing وDiscovery، مع عدم إخفاء أن السلوك محلي تجريبي. |
| قائمة حقول غنية | تمثلها العينة المحلية فقط: الاسم، الاتصال، الموقع، الحضور الرقمي، التقييم والمراجعات. |

## حدود مقصودة

لا يتصل النموذج بـGoogle Maps أو محرك Scraping أو Proxy أو API. لا يجمع بيانات فعلية ولا يقدم ادعاء credits حقيقية. لا تتأثر بوابة **CRM نمو**: تظل ترقية اختيارية مستقلة تظهر بعد نجاح الاستخراج أو التصدير.
