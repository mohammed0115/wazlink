# دليل عرض «نمو»

«نمو» هو Prototype عربي RTL لمحرك مبيعات يربط اكتشاف الشركات وتحليل الفرص وإدارة العملاء والصفقات والمحادثات والأتمتة والتحليلات ضمن سياق واحد قابل للتتبع.

> **حد العرض:** جميع البيانات والإجراءات داخل الجلسة الحالية تجريبية ومحلية. لا يوجد Backend أو حفظ دائم أو APIs حقيقية أو WhatsApp أو Google Maps أو Calendar أو LLM خارجي أو OAuth أو دفع حقيقي.

## الدخول والبداية

استخدم أي بريد بصيغة صحيحة وكلمة مرور غير فارغة في `#/login` للدخول التجريبي. إذا كانت جلسة الإعداد غير مكتملة، أكمل Onboarding ذي الخطوات الخمس أو استخدم «تجاوز الآن» في الخطوة الأخيرة للانتقال إلى Dashboard.

## Fixtures الأساسية

`SRC-1001 → JOB-1028 → BUS-1042 → LEAD-1042 → DEAL-4042 → CONV-3042` هو مسار العرض الرئيسي. سلسلة الإيراد المعترف به تبقى `REV-4061/REV-4062/REV-4063` مع Touchpoints `ATT-4061/ATT-4062/ATT-4063`. لا تدّعي الصفقة `DEAL-4042` أنها خلقت حدث إيراد جديد؛ الإغلاق كرابحة لا ينشئ RevenueEvent.

## حدود يجب ذكرها في العرض

يُسمح للمستخدم بمحاكاة الربط والفصل وإعادة المحاولة للتكاملات، لكنها لا تنفذ طلب شبكة. Copilot وAgent ينتجان اقتراحات حتمية محلية؛ لا يوجد إرسال تلقائي، وأي رسالة outbound تكون `senderType = user`. الفوترة تعرض وسيلة دفع وفواتير Mock فقط، ولا تغير RevenueEvent أو AttributionTouchpoint. عند refresh تعود الذاكرة إلى Fixtures الأساسية.
